# X 12.17.0 下载功能修复验证

**日期**: 2026-08-18
**背景**: X 自动从 12.13.0 升级到 **12.17.0-release.0 (312170000)** 后，推文下载功能看似失效（"seems after update X App, the download not work"）。本文记录诊断、修复与验证过程。

---

## 诊断

1. **hook 在 12.17.0 上初始化正常** — 所有 hook（`MainActivityHook`、`ShareMediaHook`、`OkHttpFilterHook` 等）均成功挂载；`com.x.android.main.MainActivity` 未变；上一会话 hook 的 Android 16 结果投递链（`com.twitter.app.common.base.g`、`androidx.fragment.app.y`）仍然命中。
2. **广告过滤与媒体捕获在 12.17.0 上正常** — 全新进程伴随网络抓取，日志输出 `captured media for tweet …` 与 `removed 7 promoted item(s)`，与 12.12/12.13 完全一致。响应结构（`tweet_results`、`media_entities`、`ApiImage`/`ApiVideo`）未变。
3. **真实原因一 — 首启媒体缓存为空**: 升级后 X 用缓存渲染首页时间线；没有网络抓取 → 没有响应经过过滤器 → 没有媒体捕获 → 分享触发查无媒体 → 对话框不弹。一旦有任何时间线/详情页抓取发生，捕获即恢复。
4. **真实原因二 — 设备端模块损坏（非代码问题）**: 调试签名 keystore 位于 `ANDROID_USER_HOME`（本机为 `E:\Temp\Android\.android\debug.keystore`），临时目录被清理后 keystore 重新生成 → 签名变化 → `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。卸载模块后其 **LSPosed scope 被静默清空**（`scope ls` → `[]`），模块虽启用但从不注入。恢复 scope 后注入正常：
   ```
   /data/adb/lspd/cli scope add icu.nullptr.twifucker com.twitter.android/0
   ```
5. **端到端验证（12.17.0）**: 分享 → "Share via…" → BACK → `ShareMediaHook: pending download for tweet … (2 items)` → "Download or Copy" 对话框显示 `1 · Image` / DOWNLOAD ALL / DISMISS。用户已确认保存成功。

## 留给未来会话的坑

- **调试 keystore 位置**: 本机 `ANDROID_USER_HOME=E:\Temp\Android\.android`。若临时目录被清理，调试密钥会重新生成 → `install -r` 签名不匹配。修复：`adb uninstall icu.nullptr.twifucker && adb install …`（模块偏好存于 X 的数据目录内，不会丢失）**并且**重新添加 scope（见上），再启用：
  ```
  /data/adb/lspd/cli modules enable icu.nullptr.twifucker
  ```
- **`lspd cli` 命令**: `modules ls --json`（不是 `list`）、`scope ls/add/rm/set <pkg> <app>/<user>`。
- **`install -r` 不清 scope；`uninstall` 会清。**
- **X 升级后的首次启动**: 时间线来自缓存 → 媒体缓存为空 → 下载看似失效，直到第一次网络抓取。并非 bug——滚动页面触发抓取即可。
- **adb over wifi 可能假死**: `adb kill-server && adb start-server && adb connect pixel6a:5555` 可恢复。
- **Gradle 缓存损坏**（`Could not read workspace metadata`）: 删除 `$GRADLE_USER_HOME/caches/8.9/transforms` 与 `kotlin-dsl` 后重新构建。
- **APK 证书检查**: `keytool -printcert -jarfile` 对仅 v2 签名的 APK 会报"不是已签名的 jar 文件"；改用 `apksigner verify --print-certs`。

## 验证命令

```bat
adb -s pixel6a:5555 shell "su -c '/data/adb/lspd/cli modules ls --json'"
adb -s pixel6a:5555 shell "su -c '/data/adb/lspd/cli scope ls icu.nullptr.twifucker --json'"
adb -s pixel6a:5555 logcat -d | grep "TwiFucker" | grep -E "Inited|captured|pending download"
```
